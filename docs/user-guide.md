# User guide

## Applicant

Register as an applicant, sign in, complete the profile, browse approved opportunities, open an opportunity, submit/withdraw an application, upload a CV/profile image, save opportunities, view recommendations, notifications, and messages.

## Provider

Register as a provider, complete the organisation profile, create/update/delete own opportunities, review applications to own opportunities, shortlist/reject/offer candidates, view dashboard/report data, and exchange messages. The provider report endpoints exist, but their current filtering is not consistently limited to one provider; see [API notes](api.md).

## Administrator

Administrator accounts cannot be self-registered. An authenticated administrator can access dashboards, the user list, all applications, opportunity approval/rejection, and reporting endpoints. Some admin navigation screens (content, settings, audit, NQF management) do not have matching backend endpoints in this repository.
